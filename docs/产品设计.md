# 智永真草千字文 · 产品规范（第二版）

包名 `app.zhencao.qianwen`。

## 定位

临帖辅助台，手机放在纸帖旁边用。在纸上用软笔或硬笔临写，App 负责出示底帖，并把拍下的临作和底帖叠在一起看。

不在屏上写字，不做笔顺动画，不模拟墨色。

## 主路径

1. 首页「接着写」：出示当前这一句的四个字，下附简体原文和释义，可切上一句、下一句。千文目录每句也附简体原文和释义；点句子编号，从那一句开始。
2. 点字进单字页，看底帖，可放大；可打开关中本与小川本并排对照。
3. 在纸上写完，拍一张整页（或从相册选）。
4. 框字：拖动、缩放、旋转照片，把纸上的字对进方框里的朱色底帖。「自动对齐」按墨迹外框和重心吸附，再手动微调。保存。
5. 朱墨重影：叠影、差异、并排三种看法，附重合、重心、字形比例提示。
6. 同一张纸接着框下一个字，直到这一张框完。

单字页和框字页屏幕常亮。

## 书体与底帖

首次打开先选真书或草书，之后只显示所选书体，可在「我的」里改。临作按书体分开记录。

两本底帖，每字真草各一张切图：

| 本子 | 资产目录 | 说明 |
| --- | --- | --- |
| 小川本墨迹 | `glyphs/ogawa/` | 默认底帖 |
| 关中本拓本 | `glyphs/guanzhong/` | 单字页可打开对照；保持拓片原色（黑底浅字），不反相不调色 |

小川本残缺的十一个字形（`tools/ink_fallback.json`）默认改用关中本，格内标「关中本补」。

来源在「我的」页署名：

- 小川本：日本京都小川家藏（国宝），图像取自书法空间（www.9610.com/zhy）刊布的全册扫描。逐字裁切、缩放。
- 关中本：东京大学综合图书馆藏（A005940），据其数字档案 IIIF 公开图像，按再利用条款署名并注明修改。逐字裁切，保持原色。

## 正文与分组

正文按通行临习所用的繁体《千字文》排列，共 1000 字、250 句、每句 4 字，顺序固定。这是临习通行本，不是某一石刻的逐字释文。

每句附简体原文和一句白话释义，写在 `tools/verse_notes.txt`（每行一句：简体四字、空格、释义）。释义求清楚简短，一句话说明字面意思，必要时括注人名、地名。「輶」保留原字，因其简化字多数字体不支持。

## 字库 JSON

文件：`app/src/main/assets/corpus.json`，由 `tools/build_corpus.py` 生成，运行时只读。

```json
{
  "schema": 3,
  "verses": [
    { "group": 0, "simplified": "天地玄黄", "meaning": "天是青黑色，地是黄色。" }
  ],
  "characters": [
    {
      "index": 0,
      "char": "天",
      "group": 0,
      "ink": "glyphs/ogawa/000",
      "rubbing": "glyphs/guanzhong/000"
    },
    {
      "index": 500,
      "char": "…",
      "group": 125,
      "ink": "glyphs/ogawa/500",
      "rubbing": "glyphs/guanzhong/500",
      "inkFallback": "glyphs/guanzhong/500",
      "inkFallbackKinds": ["cao"]
    }
  ]
}
```

约定：

- `verses` 共 250 项，与句序一致，给出每句的简体原文和释义。
- `index` 从 0 到 999，与正文位置一致；`group = index / 4`。
- `ink`、`rubbing` 是切图路径前缀，实际文件为 `<前缀>_zhen.webp` 和 `<前缀>_cao.webp`，512×512。
- `inkFallbackKinds` 列出默认改用关中本的书体。

## 临作比对

比对只看墨迹落点，不是评分。界面写明「供对照，不是评分」。

- 墨迹提取（`data/InkAnalysis.kt`，纯 Kotlin，有单元测试）：缩到 256×256，取 RGB 最大通道作亮度，让米字格红线不算墨；最大值滤波加模糊估计纸色，按纸色归一，Otsu 定阈值；去小斑点、填小孔。框出的临作还去掉碰到方框边缘的墨块（邻字）。关中本按浅色墨处理。
- 重合：底帖墨迹被临作覆盖的比例、临作落在底帖上的比例，各留约 2% 边长的容差，取两者调和平均。
- 重心偏移、字形宽高比：比较两者墨迹的重心和外框。
- 差异图：朱色是底帖有、临作没写到；青色是临作多写的；墨色是重合。

## 数据

本机 Room 数据库，没有账号，不联网：

- `settings`：所选书体、当前句。
- `practices`：每次临作的字、书体、时间、裁切图路径、重合度与重心偏移。裁切图存在应用私有目录 `files/practice/`。

相机只用于拍临作。整页照片只留在内存和缓存里，保存下来的是每个字的 512×512 裁切。

## 不做

屏上书写、笔顺动画、测验、打卡与每日推字、墨迹物理、账号与云同步、会员和商城。
