# 智勇真草千字文 · 产品规范（第一版）

包名 `app.zhencao.qianwen`。

## 定位

临帖辅助台，手机放在纸帖旁边用。主场景是软笔或硬笔在纸上临写，App 负责把一个草字讲清楚，并让临作和底帖叠在一起看。

屏上书写只记录结构：手指或手写笔留下轨迹，压感只改变线宽，用来和底帖重影。不模拟飞白、顿笔和水墨。笔刷物理不在这一版。

## 主路径

1. 首页给出 4 字或 8 字。
2. 进入单字工作室，真草对照。
3. 播放草书笔顺，区分实笔和牵丝。
4. 在纸上临，再拍照对齐；或直接在屏上临写。
5. 重影查看外框重合和重心偏移。
6. 测验用四选一：看草书认汉字，或看真书选草形。

首页只出示字，不打卡，也不按日布置。换一天再打开，才往后翻一批。样例字排完后，会说明其余字库还在制作。

## 版本模型

数据层有两轨，资源 ID 固定：

| id | 含义 | 第一版界面文案 |
| --- | --- | --- |
| `ink` | 墨迹系统，预留给小川本 | 墨迹示意 |
| `rubbing` | 拓本系统，预留给关中本 | 拓本示意 |

第一版没有可授权的原帖切图。两轨都用程序绘制的示意图，界面写明「不是小川本或关中本」。以后换成切图时，只填 `ink` / `rubbing` 字段，不改 ID。

「关东本」不是正式版本名。黑白反相、米字格、九宫格、回宫格、左右或上下排版，都是视图选项，存在本机设置里。

## 正文与分组

正文字库按通行临习所用的繁体《千字文》排列，共 1000 字、250 组、每组 4 字，顺序固定。

这是临习通行本，不是某一石刻的逐字释文。异写（例如恆岱 / 泰岱）等原帖核对之后单独标记，不并进同一个练习项。第一版样本没有异写条目。

前 10 组（40 字）为可用样例，带草书贝塞尔笔顺。其余 240 组在目录中可见正文，状态为「字库制作中」，不能进入临习。

## 字库 JSON

文件：`app/src/main/assets/corpus.json`。运行时只读，不做骨架提取。

```json
{
  "schema": 1,
  "placeholderGlyphs": true,
  "characters": [
    {
      "index": 0,
      "char": "天",
      "group": 0,
      "slot": 0,
      "available": true,
      "ink": null,
      "rubbing": null,
      "caoStrokes": [
        { "order": 1, "kind": "solid", "path": "M 0.70 0.22 C 0.50 0.20 0.30 0.28 0.22 0.34" }
      ]
    }
  ]
}
```

约定：

- `index` 从 0 到 999，与正文位置一致。`group = index / 4`，`slot = index % 4`。
- `ink`、`rubbing` 是原帖切图的资产路径。空值表示使用示意图。
- `caoStrokes` 使用 SVG 路径，坐标在 0–1 方框内。命令支持 M/L/C/Q/Z 及小写相对坐标。
- `kind` 为 `solid`（实笔）或 `silk`（牵丝）。
- 真书侧第一版用字体画出汉字，不做楷书笔顺。动画只播放草书。
- 高清图包、付费开关不在这份 JSON 里，也不接支付。

## 第一版范围

安装后可以用样例走完：看字、对照、笔顺、屏写或拍照重影、四选一。

进度存在本机 Room 数据库：每日出示的字、测验对错、视图偏好。没有账号，也没有云同步。

这一版明确不做：全本生产级骨架、墨迹物理、OpenGL 笔刷、运行时矢量化、自动批改默写、会员和商城。

结构提示只比较外框重合度（IoU）和重心偏移，供对照，不称作评分。
