# 智永真草千字文

临帖辅助台。手机放在纸帖旁边，App 出示底帖，并把拍下的临作和底帖叠在一起看。

不在屏上写字，不做笔顺动画，不模拟墨色。本机记录，没有账号，不联网。

## 安装

需要 Android 8.0 及以上。从 [Releases](https://github.com/zltl/zhiyong/releases) 下载 `zhiyong-0.2.1.apk`，允许安装未知来源后安装。

当前包用调试签名。以后若换成正式签名，需要先卸载再装。

## 用法

1. 首次打开选真书或草书（之后可在「我的」里改）。
2. 首页「接着写」出示当前一句四个字，下附简体原文和释义；可翻句，或从千文目录点编号跳转。
3. 点字进单字页看底帖，可放大；可打开关中本与小川本并排对照。
4. 在纸上写完，拍照或从相册选一张整页。
5. 框字：拖动、缩放、旋转，把纸上的字对进方框里的朱色底帖。「自动对齐」按墨迹外框和重心吸附，再手动微调。
6. 保存后看朱墨重影：叠影、差异、并排。提示只供对照，不是评分。同一张纸可以接着框下一个字。

单字页和框字页会保持屏幕常亮。

## 底帖

| 本子 | 用途 |
| --- | --- |
| 小川本墨迹 | 默认底帖 |
| 关中本拓本 | 单字页对照；保持拓片原色。小川本残缺的十一个字形默认改用此本，格内标「关中本补」 |

正文按通行临习所用的繁体《千字文》排列，共 1000 字、250 句。这是临习通行本，不是某一石刻的逐字释文。

来源署名也写在应用的「我的」页：

- 小川本：日本京都小川家藏（国宝），图像取自[书法空间](http://www.9610.com/zhy)刊布的全册扫描，逐字裁切、缩放。
- 关中本：《関中本真草千字文》，东京大学综合图书馆藏（A005940），据其数字档案 IIIF 公开图像，按再利用条款署名并注明修改。逐字裁切，保持原色。

## 从源码构建

需要 JDK 17 和 Android SDK（compileSdk 35）。

```bat
gradlew.bat :app:assembleDebug
```

产物在 `app/build/outputs/apk/debug/app-debug.apk`。

字库由 `tools/build_corpus.py` 生成到 `app/src/main/assets/corpus.json`，切图在 `glyphs/ogawa/` 与 `glyphs/guanzhong/`。完整约定见 [产品设计](docs/产品设计.md)。

## 不做

屏上书写、笔顺动画、测验、打卡与每日推字、账号与云同步、会员和商城。
